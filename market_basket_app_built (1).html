How this app works

Dataset — view the raw and cleaned transaction log, and download either as CSV.
Data Analysis — see the cleaning steps applied and basic statistics.
Frequent Itemsets — product combinations that appear together often enough to matter.
Association Rules — "if A then B" rules with Support, Confidence and Lift.
Product Recommendations — pick a product, get instant cross-sell/upsell suggestions.
Visualizations — five charts summarizing the whole analysis.

Project Notes

About This Project

Objective

Analyze customer shopping transaction data, discover which products are frequently purchased together using the Apriori algorithm, and generate actionable cross-selling and upselling product recommendations for a retail or e-commerce business.

Technology stack

This build runs entirely in the browser: a hand-written JavaScript port of the Apriori algorithm and association-rule mining, styled as a self-contained web app with Chart.js visualizations. A parallel Python edition (Pandas, NumPy, MLxtend, Streamlit, Plotly) is available for a server-hosted version of the same analysis.

Key concepts

Support — how frequently an itemset appears across all transactions.
Confidence — likelihood the consequent is purchased given the antecedent was purchased.
Lift — how much more likely the consequent is bought with the antecedent than by chance alone (lift > 1 marks a genuine positive association).

Business use case

Cross-selling — recommending complementary products, e.g. Bread → Butter.
Upselling — recommending a higher-value add-on or upgrade, e.g. Milk → Cheese.

Use the sliders in the sidebar to change the Support, Confidence and Lift thresholds live, and watch the itemsets, rules and recommendations update everywhere in the app.
